# HSI-compression-benchmark

This repository is produced for the review article titled **"Hyperspectral image compression with deep learning: A review"**. Its objective is to facilitate new readers and developers in the field of hyperspectral image compression using deep learning.

> **Note:** This repository contains supplementary materials, code implementations, and resources referenced in the review article.

## Citation

If you use this repository or reference our work, please cite:

> F. Saeed, S. Liu, Y. Liu, and J. Chen, "Hyperspectral image compression with deep learning: A review," Signal Processing, vol. 239, p. 110270, 2026, available online: https://www.sciencedirect.com/science/article/abs/pii/S0165168425003846
